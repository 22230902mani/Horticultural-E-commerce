# 🧠 System Overview

**MANIHUB Horticultural E-Commerce Protocol** is an intelligent agriculture-focused e-commerce and crop management platform developed to assist farmers, buyers, and agricultural businesses.

The platform provides:
- Smart crop browsing
- Real-time market insights
- Storage recommendations
- Value addition information
- Crop-specific analytics
- Responsive e-commerce experience

The system is designed to bridge technology and agriculture through modern web solutions.

# 🛠️ Installation Protocol

## 1️⃣ Clone Repository

```bash
git clone https://github.com/22230902mani/Horticultural-E-commerce.git
cd Horticultural-E-commerce
```

---

## 2️⃣ Setup Backend Environment

```bash
Install XAMPP / WAMP
Move project folder into htdocs
Start Apache & MySQL
```

---

## 3️⃣ Configure Database

- Open phpMyAdmin
- Create database
- Import SQL file
- Configure PHP database connection

---

## 4️⃣ Launch Application

```txt
http://localhost/Horticultural-E-commerce/
```
